J&B LAB Firebase 로그인 설정

1. Firebase Console에서 jb-lab-pro 프로젝트를 엽니다.
2. Authentication > Sign-in method에서 Google 로그인을 사용 설정합니다.
3. Authentication > Settings > Authorized domains에 실제 홈페이지 도메인을 추가합니다.
   GitHub Pages를 쓴다면 예: petrick0255-create.github.io
4. index.html, app.js, firebase.js, style.css, logo.png를 함께 배포합니다.

동작
- 홈페이지 내용은 로그인 전에도 표시됩니다.
- 로그인 전에는 홈페이지 내부의 모든 클릭 기능이 잠깁니다.
- parkjunbum0255@gmail.com Google 계정으로 로그인한 경우에만
  프로젝트, 분류, 메일, 상단 링크, 우측 바로가기 등 모든 클릭 기능이 활성화됩니다.
- 다른 Google 계정으로 로그인하면 즉시 로그아웃 처리됩니다.

바로가기 추가
- app.js 상단의 quickLinkData 배열에 기존 항목과 같은 형식으로 추가하세요.

보안 참고
- Firebase 웹 설정의 apiKey는 브라우저에서 공개되는 식별 정보입니다.
- 현재 링크 주소는 app.js에 있으므로 소스 코드를 열면 확인할 수 있습니다.
  링크 자체 또는 데이터를 비밀로 보호하려면 Firestore에 저장하고
  Firebase 보안 규칙에서 본인의 Firebase UID만 허용해야 합니다.
